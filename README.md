# Multiplication Table Using Flexbox 


Through this exercise, I learned how to create and style a multiplication table using flexbox. It helped me understand how structure and layout work together, especially when designing responsive elements.

I found this exercise a bit challenging because I was new to GitHub and still learning how to commit and push files properly. The “Froggy” game we played in class was really helpful for memorizing flexbox properties and understanding how they affect layout positioning.
